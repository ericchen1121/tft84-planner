 A LITTLE CLARITY

How the score works

By default, add the number of champions in every active trait. A champion can contribute to more than one trait.

3 Choreographer+3
2 Bodyguard+2
1 Synthwave unique trait+1
1 Arcanist needs 2 to activate+0

The default minimum is 16. Unique traits count unless you switch them off.

Frontline means attack range ≤2. Four-cost backline means attack range >2 and a marksman, caster, or ranged ammo specialist role. This includes Jhin.

Baron Nashor uses 2 population slots. Seven-cost champions can be included, but unlock requirements and shop access are not simulated.

Collab assignments and Sona's featured trait vary by game. Specify them in Advanced options; otherwise only the source roster's printed traits count.

A stopped or timed-out search is labeled partial. Only a completed search represents all qualifying lineups. The default preset contains all 68,766 verified matches.
